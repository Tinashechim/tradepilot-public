# TradePilot

**By Tinashe Chimanikire**

TradePilot is a Windows desktop subscription app with MT4/MT5 companions for position sizing, basket management, Point Measurer, pending orders, account payment approval, analytics and PDF documents.

The subscription product is available through [Microsoft Store](https://apps.microsoft.com/detail/restricted/9NJ7TWJSJ56G). Source code remains private to protect the commercial subscription service. This public repository describes the product and verified release status. Installation remains free for the private tester audience.

## Release status

Installed Store version **1.0.25.0**, Windows Status OK, was verified on 8 October 2026. The certification monitor remains paused.

Version **1.0.26.0 is in development and has not been submitted**. Saved changes include named simultaneous lead strategies with assigned follower groups, isolated copy references, broker-aware margin safeguards, user-directed follower orders, manual/system history summaries, daily target update choices, local password/inactivity locking, per-lead company and report information, separate generated account IDs, dated audit PDFs, notification preferences and battery warnings. **195 isolated regression checks pass**, alongside temporary desktop form/lock checks and rendered PDF checks. These results do not establish native live-copying success or installed availability of the development features.

Both updated native companions compile without errors or warnings. Authenticated MT4/MT5 connection replies and history imports were verified with trading OFF and no open positions. One IFX MT5 dry sizing/margin example and the three-column layout were inspected. The newest display and interaction corrections still need native retesting; these checks do not establish successful trade execution.

Current development work includes separate Commission and Swap basket displays, original-day carry-over progress, a shared daily Update confirmation, Ratio target equivalents, loss protection, and selected Lead/Follower PDF graphs with dated execution summaries. Charges are included once in net results; current spread estimates are distinguished from historical entry costs.

Remaining release gates include native display/cancellation checks, additional broker-contract sizing and minimum/margin boundaries, chart recovery/owner changes, original-day basket rollover, user-controlled scheduled execution and end-to-end demo copying, final compiled-only download artifacts, packaging and Store-signed startup. No Microsoft upload will occur until every requested requirement and relevant test passes. Earlier development packages are obsolete. TradePilot cannot override broker server-side automated-trading restrictions.

## Account setup and documents

Each connected account uses its own terminal installation. Guided setup verifies an actual registered-account reply. Broker passwords stay in the terminal. Trading permissions are controlled by the user. Paid records approval without charging money; future paid months capture their opening balance when that broker month starts.

Broker records provide read-only account values, trading results, costs, tiers and connection coverage. PDFs use a consistent design and support View, Download and Email. Historical results and timing observations do not promise future performance.

Only MT4 and MT5 hedging connectors are currently supported. Additional trading and crypto connectors require implementation and verification. End-to-end demo copying and scheduled execution remain subject to native testing. Email delivery requires a configured supported sender and enabled delivery.
