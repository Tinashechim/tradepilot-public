# TradePilot

**By Tinashe Chimanikire**

TradePilot is a Windows desktop subscription app with MT4/MT5 companions for position sizing, basket management, Point Measurer, pending orders, account payment approval, analytics and PDF documents.

The subscription product is available through [Microsoft Store](https://apps.microsoft.com/detail/restricted/9NJ7TWJSJ56G). Source code remains private to protect the commercial subscription service. This public repository describes the product and verified release status. Installation remains free for the private tester audience.

## Release status

Installed Store version **1.0.25.0**, Windows Status OK, was verified on 8 October 2026. The certification monitor remains paused.

Version **1.0.26.0 is in development and has not been submitted**. Saved changes include named simultaneous lead strategies with assigned follower groups, isolated copy references, broker-aware margin safeguards, user-directed follower orders, manual/system history summaries, daily target update choices, local password/inactivity locking, per-lead company and report information, separate generated account IDs, dated audit PDFs, notification preferences and battery warnings. **155 isolated regression checks pass**, alongside temporary desktop form/lock checks and rendered PDF checks. These results do not establish native live-copying success or installed availability of the development features.

Remaining release gates include live IFX connection/sizing checks, native chart recovery, the full daily risk-limit/Ratio controls, broader filtered analytics, remaining native notification/spread details, final packaging and Store-signed startup. The earlier development build is obsolete and will not be uploaded. TradePilot cannot override a broker's server-side automated-trading restrictions.

## Account setup and documents

Each connected account uses its own terminal installation. Guided setup verifies an actual registered-account reply. Broker passwords stay in the terminal. Trading permissions are controlled by the user. Paid records approval without charging money; future paid months capture their opening balance when that broker month starts.

Broker records provide read-only account values, trading results, costs, tiers and connection coverage. PDFs use a consistent design and support View, Download and Email. Historical results and timing observations do not promise future performance.

Only MT4 and MT5 hedging connectors are currently supported. Additional trading and crypto connectors require implementation and verification. End-to-end demo copying and scheduled execution remain subject to native testing. Email delivery requires a configured supported sender and enabled delivery.
